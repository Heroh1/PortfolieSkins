Admin / Skins

Ajoute ou supprime un skin du portfolio. Retour au portfolio

1. Connexion (une seule fois)

Il faut un « jeton » GitHub qui autorise ce site à ajouter des fichiers dans ton dépôt. Il reste uniquement dans ton navigateur.

  1. Ouvre github.com/settings/personal-access-tokens/new
  2. Nom : portfolio. Expiration : à ton choix.
  3. « Repository access » : Only select repositories, puis choisis PortfolieSkins.
  4. « Permissions », « Repository permissions » : Contents en Read and write.
  5. Clique sur Generate token, copie-le et colle-le ici.
